# 作業進捗

## 現在の作業

- 目的: リプレイ再生の一時停止地点から、永続記録対象外のプレイヤー操作へ分岐できるようにする。
- 状態: 完了

## 完了事項

- Aで一時停止、停止中のAで確認ダイアログ、`YES`でプレイヤー操作へ分岐する入力仕様を定義した。
- `NO`初期選択、上下選択、A決定、Bキャンセルと、ダイアログ中の入力排他を定義した。
- 安定状態だけでなく、待ち時間・HOLD・DROP・マージ・回転などの途中状態もそのまま引き継ぐ分岐規則を定義した。
- 再生状態と永続記録資格を分離し、分岐後もリプレイ、各種記録、統計、中断データ、将来の実績と報酬を保存しない方針を定義した。
- ゲーム仕様書と入力・リプレイ設計書を更新した。
- `game_state.lua`へ追加する状態と、既存の記録資格を共通の`persistentRecordEligible`へ統合する方針を定義した。
- `game_controller.lua`の分岐関数、入力優先順、再生専用状態の破棄順、永続記録ガードを定義した。
- `overlay_renderer.lua`、`game_renderer.lua`、`scene_game_normal.lua`など、描画とシーンの改修方法を定義した。
- 実装後に確認する分岐地点とdatastore非更新の検証項目を定義した。
- リプレイ一時停止中のAで確認ダイアログを開き、上下選択、A決定、Bキャンセルを処理する入力状態遷移を実装した。
- `YES`決定時に再生専用状態だけを破棄し、盤面、NEXT、HOLD、乱数、UNDO、進行中アニメーションを保持してプレイヤー入力へ切り替える処理を実装した。
- 分岐後にAuto Playとリプレイ記録を停止し、Retryでは通常の新規NORMALへ移行するようにした。
- `persistentRecordEligible`と`canWritePersistentProgress()`を追加し、統計、最高記録、中断保存、リプレイ保存の永続書き込みを共通で抑止した。
- `statisticsRunEligible`と`levelRecordEligible`を廃止し、中断データ形式をバージョン2へ更新した。
- 確認ダイアログ、一時停止操作案内、オーバーレイ優先順、システムメニュー更新を実装した。

## 未完了事項

- 前回実装したリプレイ早送りのSimulator確認も未実施。

## 判断・注意事項

- 分岐時にseedから再構築せず、現在の論理状態・乱数状態・UNDO・進行中アニメーションを保持する。
- 未適用のリプレイイベントだけを破棄し、すでに受理済みの操作は取り消さない。
- 分岐後のラン内スコアやレベルは通常どおり進行するが、永続記録資格はラン終了まで復活させない。
- 分岐後は中断保存を許可せず、Retryは新しい記録対象NORMALを開始する。
- 永続記録資格はREWINDで復活させないため、UNDOスナップショットへ含めない。
- 分岐後のゲームオーバーでは`finishReplayRecordingIfNeeded()`がチェックサム検証・中断データ削除・リプレイ保存を行わず、`REPLAY NOT SAVED`を表示しないようにする。
- 以前からの無関係な差分は変更していない。
