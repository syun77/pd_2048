## 短い説明／キャッチコピー

落として、つないで、盤面が回る。2048×回転落ちものパズル！

## 紹介文

『KuruKuru512』は、2048のマージルールをベースにしたPlaydate専用の落ちものパズルです。

舞台は、中央の回転軸を除く24マスで構成された5×5の盤面。左右キーで落下列を選び、下キーで次のブロックを落とします。同じ数字をつなげて大きなブロックを作りましょう。

しかし、ブロックの位置やマージ結果によって盤面は90度回転します。積み上げた配置も、回転すればまったく違う形に。落下先だけでなく、次に起こる回転まで読みながら、より大きな数字を目指してください。

## Short Description / Tagline

Drop, merge, and spin the board! A rotating 2048-style puzzle for Playdate.

## Description

KuruKuru512 is a falling-block puzzle designed exclusively for Playdate, based on the merging rules of 2048.
The game takes place on a 5×5 board with 24 playable spaces surrounding a central pivot. Choose a column with the Left and Right buttons, then press Down to drop the next block. Combine matching numbers to create increasingly larger blocks.
But there’s a twist: depending on where blocks land and how they merge, the entire board rotates 90 degrees. A carefully arranged board can transform into something completely different in an instant. Plan where each block will fall, anticipate the next rotation, and aim for the biggest number you can create.
