# ツール作成時の注意事項

## Tkinter の Listbox

Tkinter の `Listbox` は、項目ごとの `state`（`normal` / `disabled`）を
`itemconfigure()` で設定できない。`itemconfigure(index, state=...)` は
`TclError: unknown option "-state"` になるため使用しない。

項目を無効に見せる場合は、次の方法を使う。

- `itemconfigure(index, foreground=...)` で文字色をグレーにする。
- `<<ListboxSelect>>` のイベントで選択項目を検証する。
- 無効項目が選択された場合は、値を変更せず選択を解除する。
- リストを再描画する場合は、プログラムによる選択変更でイベントが発火しても
  編集処理を実行しないよう、更新中フラグを設ける。

Tkinter ウィジェットのオプションは、利用するウィジェットが実際に対応しているか
確認してから使用し、対応していないオプションを別ウィジェットの仕様から推測して
追加しない。

## 色の指定

OSのライトテーマ・ダークテーマのどちらでも読めるよう、文字色や背景色を黒・白に
固定しない。Tkinterウィジェットの現在のテーマ色（`cget("foreground")`、
`cget("background")` など）を取得して使用する。

テーマの既定色が環境によって適切でない場合は、背景色の明度を判定して文字色を
選び、無効項目などの派生色は文字色と背景色の中間色から生成する。色の組み合わせを
変更した場合は、ライトテーマとダークテーマの両方で文字が背景に埋もれないことを
確認する。

## 未保存状態とウィンドウタイトル

編集データに未保存の変更がある場合は、現在のファイル名の直後に `*` を表示する。
表示形式は `001.json* - アプリケーション名` とする。

- 編集操作で状態を変更したら、未保存フラグを立てる。
- 未保存フラグを変更する処理から、タイトル更新処理を必ず呼び出す。
- 保存、新規作成、ファイル読み込みが完了したら未保存フラグを解除し、タイトルから
  `*` を外す。
- UNDO / REDO も編集状態を変更するため、タイトルを更新する。
