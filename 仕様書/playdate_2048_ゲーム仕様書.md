# Playdate版 2048回転マージ落ちものパズル 仕様書

## 1. 概要

2048のマージルールをベースに、5×5マスの盤面へブロックを落とすパズルゲーム。
中央マスを回転軸として盤面が90度回転し、回転後に重力を再適用する。

プレイヤーは左右キーで落下位置を選び、下キーでブロックを落下させる。
落下位置そのものに加えて、落下後の盤面回転・再配置・マージ連鎖を予測することがゲームの中心となる。

対象ハードウェアはPlaydate、画面解像度は400×240ピクセルとする。

## 2. 基本仕様

| 項目 | 仕様 |
|---|---|
| 対応機種 | Playdate |
| 画面解像度 | 400×240 px |
| 盤面 | 5×5マス |
| 中央マス | 回転軸。ブロック配置不可 |
| 使用可能マス | 24マス |
| 入力 | 左、右、下、A、B |
| ブロック | 2048形式の数値ブロック |
| マージ | 同じ値の隣接ブロックを2倍にする |
| 終了条件 | 使用可能な24マスが埋まり、新しいブロックを置けない |

## 3. 盤面座標

盤面の論理座標は左上を`(0, 0)`、右下を`(4, 4)`とする。

```text
(0,0) (1,0) (2,0) (3,0) (4,0)
(0,1) (1,1) (2,1) (3,1) (4,1)
(0,2) (1,2) (2,2) (3,2) (4,2)
(0,3) (1,3) (2,3) (3,3) (4,3)
(0,4) (1,4) (2,4) (3,4) (4,4)
```

`(2, 2)`は回転軸であり、常に空きマスとして扱う。ブロックの移動先・落下先・マージ先にはならない。

### 3.1 盤面の表示サイズ

画面上の盤面は次の矩形に配置する。

| 項目 | 値 |
|---|---:|
| 盤面表示領域 | x=80〜319、y=20〜219 |
| 1マスの表示サイズ | 40×40 px |
| 盤面の表示サイズ | 200×200 px |
| マス間の罫線 | 1〜2 px |
| 盤面左上 | x=100、y=20 |

実装上のセル矩形は次で求める。

```text
cellX = 100 + x * 40
cellY = 20 + y * 40
```

画面上部の`y=0〜19`はタイトルまたは次ブロック表示、画面下部の`y=220〜239`は操作ヒントやスコア表示に使用できる。

## 4. 落下操作

### 4.1 基本操作

- 左キー：落下位置を1列左へ移動する。
- 右キー：落下位置を1列右へ移動する。
- 下キー：現在の列へブロックを落とし、手を確定する。
- Aボタン：次ブロックまたは詳細情報を表示する用途に使用できる。
- Bボタン：ポーズ画面を開く。ポーズ中は盤面を更新しない。

落下位置は`x=0〜4`の5列で管理する。左右キーでは盤面の外へ移動しない。
中央列`x=2`にも落下できるが、中央マス`(2,2)`を通過または占有することはできない。

### 4.2 落下可能位置

ブロックは、現在の列において、盤面の下方向へ移動できる最終位置まで落下する。
ただし、次のいずれかを満たすセルにのみ設置できる。

1. 盤面の下端に接している。
2. 下方向の隣接セルに既存ブロックがある。
3. 左隣または右隣のセルに既存ブロックがある。

中央の回転軸セルは接着面として利用できない。
斜め隣接および上方向のみの隣接は接着とはみなさない。
盤面から浮いた状態になる位置には配置しない。

## 5. 盤面回転

左右キーは落下位置の選択に使用するため、回転方向を直接入力しない。
本仕様では、ブロックを落とした列と中央列との関係から回転方向を決定する。

| 落下列 | 回転 |
|---|---|
| x=0、x=1 | 反時計回りに90度 |
| x=2 | 回転なし |
| x=3、x=4 | 時計回りに90度 |

この方式により、左右キーで「どの列へ落とすか」と「落下後に盤面をどちらへ回すか」を同時に選択できる。
中央列は回転を起こさない安全な選択肢となるが、中央マス自体には配置できない。

### 5.1 回転変換

盤面を論理的に回転させる。5×5盤面の座標変換は次の通り。

時計回り：

```text
newX = 4 - oldY
newY = oldX
```

反時計回り：

```text
newX = oldY
newY = 4 - oldX
```

回転軸`(2,2)`は回転後も空きセルである。

画面表示だけを回転させるのではなく、盤面データの座標を変換する。

## 6. 手の解決順序

下キーが押されると、次の順序で1手を処理する。

```text
入力確定
  ↓
落下位置を決定
  ↓
配置可能な最終セルを検索
  ↓
ブロックを配置
  ↓
マージ処理
  ↓
落下列に応じて盤面を回転
  ↓
重力による下方向への移動は行わない
  ↓
マージ処理
  ↓
落下・マージがなくなるまで繰り返す
  ↓
次ブロックを生成
  ↓
ゲームオーバー判定
```

盤面を回転しても、回転後に画面下方向へブロックを移動させる重力処理は行わない。
回転によって各ブロックが移動した位置を、そのまま次の盤面状態として扱う。

## 7. マージルール

- 上下左右に隣接した同じ値のブロックをマージする。
- 1回のマージで、同じ値の2ブロックを1つの2倍値ブロックに変換する。
- 1つのブロックが同一手の中で複数回マージすることはできない。
- マージ後に空きセルができても、重力による下方向の詰めは行わない。
- 新たな同値隣接が生じた場合は、連鎖マージを行う。
- 中央の回転軸セルをまたいだ隣接は成立しない。
- マージ時は、移動元ブロックが移動先ブロックへ向かって移動するアニメーションを表示する。
- マージ結果はアニメーション完了時に盤面へ反映する。
- 連鎖マージが発生する場合は、前のマージアニメーション完了後に次のマージアニメーションを開始する。

マージでは、落下したブロックを基準に、同値の隣接ブロックへ移動させる形で合体させる。
連鎖マージでは、直前に生成されたマージブロックを次の基準ブロックとする。
マージ後のブロックが上下左右のどのブロックにも接続しない候補は避け、中心から孤立しない配置を最優先する。
孤立しない候補が複数ある場合、下方向、左方向、右方向、上方向の順に優先する。
視覚上の不自然な差を避けるため、最終的には1手単位で結果が再現できるようにする。

## 8. ブロック生成

初期ブロックおよび次ブロックは、通常の2048と同様に低い値を中心に生成する。

初期実装の推奨値：

- `2`：90%
- `4`：10%
- 現在の盤面の最大タイル値の半分：2%（その値が`4`より大きい場合のみ）

通常の`2`・`4`の抽選は維持し、最大タイル値の半分は追加の低確率候補として扱う。
例えば盤面の最大値が`16`の場合、`8`が低確率で出現する。

生成したブロックが配置できる場所を持たない場合、その時点でゲームオーバーとする。
乱数の使用にはPlaydate SDKの乱数機能を使用し、同じ乱数系列を指定した場合は同じ結果を再現できるようにする。

## 9. スコア

マージで生成された値をスコアに加算する。

```text
2 + 2 = 4  → +4点
4 + 4 = 8  → +8点
8 + 8 = 16 → +16点
```

画面下部に現在スコアを表示する。ハイスコアはゲーム終了時に保存し、次回起動時にも表示できるようにする。

## 10. 画面構成

```text
┌────────────────────────────────────────┐
│ 2048 ROTATE                 SCORE 00000 │ y=0〜19
│                                        │
│        ┌────────────────────┐          │
│        │     5×5盤面        │          │ y=20〜219
│        │    中央は回転軸     │          │
│        └────────────────────┘          │
│ ←/→ SELECT        ▼ DROP   A/B MENU   │ y=220〜239
└────────────────────────────────────────┘
```

表示要素：

- 現在スコア
- 次に落下するブロック（盤面上部の選択列に表示）
- 次の次に落下するブロック（画面下部の`NEXT`枠内に表示）
- 現在の落下列を示すカーソル
- 5×5盤面
- 中央の回転軸表示
- 操作ヒント

### 10.1 落下カーソル

- 現在選択中の列を盤面上部のハイライトで示す。
- 中央列を選択した場合は、回転なしであることが分かる表示にする。
- 配置不能な列は警告色または点滅で示す。
- 下キーを押すまで、盤面のブロックは変更しない。

## 11. ゲーム状態

最低限、次の状態を持つ。

```text
TITLE       タイトル画面
PLAYING     プレイ中
DROPPING    落下アニメーション中
MERGING     マージアニメーション中
ROTATING    回転アニメーション中
NEXT_ANIM   NEXT枠から次の落下位置への移動アニメーション中
PAUSED      ポーズ中
GAME_OVER   ゲームオーバー
```

`RESOLVING`中は入力を受け付けず、盤面が安定してから次ブロックを表示する。
演出を省略する場合でも、内部処理は同じ順序で完了させる。

## 12. ゲームオーバー判定

次のいずれかを満たした場合、ゲームオーバーとする。

1. 中央セルを除く24セルがすべてブロックで埋まっている。
2. 次ブロックを5列のいずれにも合法的に配置できない。

マージによって空きセルが生じた場合は、ゲームオーバーを解除してプレイを継続する。

## 13. Playdate実装上の前提

- 画面更新はPlaydateの標準描画ループで行う。
- 盤面データは5×5の2次元配列で保持する。
- 中央セルは常に`nil`または空セルとして扱う。
- ブロックの移動・回転・マージは、表示処理から分離したゲームロジックとして実装する。
- 描画は1マス40×40pxを基本とし、Playdateの1-bit表示でも値を判別できるよう、数字・枠線・パターンを併用する。
- 回転・落下・マージには短いアニメーションを付ける。処理中は次の落下入力を受け付けない。
- 400×240pxに収めるため、盤面を画面中央に配置し、情報表示は上下20pxずつの領域に限定する。

## 14. 未確定事項

実装前に次の項目を決定する。

- ブロックの形状を1マスブロックとするか、複数マスのピースとするか
- 回転なしとなる中央列への落下を許可するか
- 回転前にマージするか、回転後にマージするか
- 盤面回転中の演出時間
- ハイスコアの保存方式
- ゲームオーバー後の再スタート操作

本仕様では、実装の単純さとプレイ時の分かりやすさを優先し、1マスブロック、中央列への落下許可、回転後に重力とマージを再計算する方式を採用する。
